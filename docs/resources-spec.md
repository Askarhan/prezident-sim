# Ресурсная экономика — спецификация (черновик 30.10)

Все количества в «единицах страны»: 1 единица = одинаковая доля экономики в любой стране (как сейчас через S.uq). Деньги — доля ВВП. Поэтому правила одинаковы для всех стран.

## Правило стоимости стройки
Полная стоимость = деньги (оплата работ) + материалы по биржевой цене.
Материалы ≈ 55% полной стоимости, деньги ≈ 45%. Своё производство → экономия; импорт ×1,6 с лимитом продавца.

|---|---|---|
| ТЭС | +4% энергии | топливо 1% |
| ГЭС | +8% энергии (лимит рек) | — |
| Солнце/ветер | +2% энергии, рейтинг +0,2 | — |
| АЭС | +12% энергии | уран |
| Агрокомплекс | +4% продовольствия | энергия 0,5% |
| Рудник (руда) | +4% руды | энергия 0,5% |
| Нефтегаз | +4% топлива | — |
Потребность = ВВП / ВВП на старте (растёт с экономикой). Старт: покрытие по профилю страны.

## Техника и боеприпасы (материалы на единицу)
- 1–2 поколение: сталь.
- 3 поколение: сталь + РЗМ (≈20% стоимости материалов).
- ПВО, ракетные комплексы, дроны, РЭБ: сталь + РЗМ (≈30%).
- Снаряды, ракеты РСЗО, бомбы: сталь. ПТУР, зенитные, крылатые/баллистические ракеты: сталь + РЗМ.
- Война: каждый день расходует нефть пропорционально задействованной армии. Нет нефти → техника воюет хуже.

## Окупаемость (цель)
Промышленность 30–45 мес., инфраструктура 40–55 мес. с бонусами, добыча — через экономию на импорте. Военные заводы: выпуск ≈ 2,5% своей цены в месяц, экспорт ограничен.
