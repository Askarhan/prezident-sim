# Картинки зданий для карточек

29 картинок для экранов «Строительство» и «Объекты по стране».

**Как делать**
1. К каждому объекту добавляй общий стиль из блока ниже, чтобы все картинки вышли одинаковыми.
2. Формат горизонтальный 16:9, ширина от 1024 px. Карточка обрезает верх и низ, поэтому главное держи в центре.
3. Имя файла берётся из первой колонки: `farm.png`, `oil.png` и так далее. Подойдут PNG или JPG.
4. Если здание вышло не того масштаба или ракурса, лучше перегенерировать: на карточках разница будет видна сразу.

**Общий стиль (добавлять в конец каждого промпта)**

```
photorealistic aerial photograph, three-quarter view from about 45 degrees, the whole object in frame and centered, soft overcast daylight, muted natural colours, light haze, plain surrounding terrain, no people, no text, no logos, no flags, no watermark, 16:9
```
