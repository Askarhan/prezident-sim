# 3D-модели техники (Blender)

Модели собираются кодом в Blender 5.x: `units.blend` лежит у автора в `D:\Projects\kabinet_units`.

- `kab_lib.py` — примитивы, материалы (реалистичные, с потёртостями).
- `kab_models.py` — строители моделей и таблицы вариантов (TANK_SPECS, IFV_SPECS, … GAME_ATLAS).
- `kab_render.py` — камера и рендер одной модели.
- `kab_atlas.py` — 8 ракурсов на модель (рендер 384 px → 96 px), сборка атласа.

Атлас для игры: `www/units/units_atlas.webp` + `units_atlas.json`: кадры 96×96, по 2 модели в строке, 8 направлений на модель (кадр d смотрит на d·45° против часовой от «востока» экрана).
Синий цвет — метка «наши»: игра перекрашивает его в красный для противника.
